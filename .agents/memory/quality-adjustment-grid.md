---
name: Quality adjustment grid
description: The SubHub quality screen uses a unified signed stock-change grid for all inventory categories.
---

The SubHub quality screen presents all current raw materials and final products as one compact list. Operators enter a signed whole-number change and a reason; positive values add stock and negative values remove stock.

**Why:** A single scan-and-enter list is faster and less error-prone for routine quality corrections than repeatedly selecting items in separate forms.

**How to apply:** Keep additions and FIFO-safe removals on the existing inventory transaction path, require a reason for every non-zero change, and submit multiple changed rows in one transaction.
